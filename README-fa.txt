راهنمای باز کردن سایت جاینو

برای مشاهده روی گوشی:
۱) فایل ZIP را کامل استخراج کنید.
۲) فایل index.html را از پوشه استخراج‌شده انتخاب کنید.
۳) از منوی اشتراک‌گذاری/بازکردن با، مرورگر Chrome یا Safari را انتخاب کنید؛ پیش‌نمایش داخل پیام‌رسان یا برنامه فایل ممکن است کد HTML را نشان دهد.

برای نمایش با یک آدرس عمومی اینترنتی، پوشه حاوی index.html را روی سرویس میزبانی سایت (مانند Netlify یا هاست شخصی) منتشر کنید. این بسته به‌تنهایی هنوز روی دامنه عمومی منتشر نشده است.
